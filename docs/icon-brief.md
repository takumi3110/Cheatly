# Cheatly アイコン制作ブリーフ

アイコン制作を依頼するための説明資料。デザイナー / AI エージェントはこのファイルだけ読めば作業に着手できることを目指す。

## 1. プロダクト概要

- **名前**: Cheatly（チートリー。"cheat sheet" + "-ly"）
- **一言で**: CLI コマンドのチートシートを、Mac のメニューバーから一瞬で引けるアプリ
- **プラットフォーム**: macOS（Tauri 製デスクトップアプリ。Mac App Store 配布を想定）
- **使われ方**: メニューバーに常駐 → トレイアイコンをクリック → 小さなウインドウが開く → 「〜したい」と話し言葉で検索 → コマンドをコピー
- **対応ツール（パック）**: Linux / Vim / Git / Docker / PowerShell / cmd / VS Code など。オフラインで使える
- **想定ユーザー**: 初心者〜上級者まで万人。コマンド名を覚えていない人でも使える
- **コンセプト**: 「ググるより、このアプリを開いた方が速い」

## 2. アイコンで伝えたいこと（優先順）

1. **コマンド / ターミナル** に関するツールであること
2. **サッと引ける早見表（チートシート）** であること
3. 堅すぎない、**親しみやすさ・軽快さ**（初心者も怖くない）

モチーフ案（あくまで参考。組み合わせ・別案も歓迎）:

- ターミナルのプロンプト記号 `>_` や `$`
- 付箋・カード・メモ（カンニングペーパー的な小さな紙）
- 「C」の頭文字との組み合わせ
- 稲妻・素早さの表現（速さの強調）

避けたいもの:

- 実在ブランドのロゴ（Git, Docker, Vim, Apple など）を含めること
- 細かい文字や多数の要素（小サイズで潰れる）
- 「チート＝ゲームの不正ツール」を連想させる表現（ドクロ、ハッカー的な怪しさ）

## 3. ビジュアル方針

アプリ本体は VS Code 風のダークテーマ。アイコンもこれに馴染ませたい。

| 用途 | 色 |
|---|---|
| アクセント（メインカラー） | `#4fc1ff`（明るいシアンブルー） |
| アクセント（明） | `#75d3ff` |
| 背景（最暗） | `#1e1e1e` |
| 背景（パネル） | `#2d2d30` |
| テキスト | `#e8e8e8` / `#cccccc` |

- トーン: モダン・フラット寄り。macOS の他アプリと並んで違和感のない質感
- 形状: macOS Big Sur 以降の角丸スクエア（squircle）の標準グリッドに従う

## 4. 必要な成果物

### A. アプリアイコン（Dock / Finder / App Store 用）

- **マスター**: 1024×1024 px の PNG（透過背景、macOS アイコングリッド準拠の角丸スクエア）
- 可能ならベクター（SVG）も
- 16px・32px に縮小しても判別できること

生成後は Tauri CLI で各サイズに展開する想定:

```bash
npm run tauri icon path/to/icon-1024.png
```

→ `src-tauri/icons/` 配下（`icon.icns`, `icon.ico`, `32x32.png`, `128x128.png`, `128x128@2x.png` など）が置き換わる。

### B. メニューバー（トレイ）アイコン

このアプリは**メニューバー常駐がメインの入口**なので、こちらも重要。

- **単色（黒 + 透過）のテンプレート画像**。macOS がライト/ダークに合わせて自動で色を反転する
- サイズ: 22×22 px（@1x）と 44×44 px（@2x）の PNG、または SVG
- アプリアイコンと同じモチーフを、線/シルエットだけで表現したシンプル版
- 現状はアプリアイコンをそのまま流用しているため、カラーのままメニューバーに出てしまっている（差し替え対象）

## 5. 現状

- `src-tauri/icons/` には Tauri のデフォルトアイコンが入っている（未デザイン）
- トレイアイコンは `src-tauri/src/lib.rs` で `app.default_window_icon()` を使用している

## 6. 依頼時に一緒に欲しいもの

- 各案のコンセプト説明（1〜2 行）
